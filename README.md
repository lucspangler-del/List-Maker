# Unit 6 - ListMaker (React)

This is a CRA-style React app scaffold located in `U6/`.

## Scripts
- `npm start` - Run dev server
- `npm run build` - Build for production
- `npm test` - Run tests (CRA)

## Storage & Sharing (next steps)
The app will store user-created lists in `localStorage` and provide a “share” mechanism. The actual UI/logic will be implemented in `src/`.
